      La velocidad del ratón establece una relación directa entre el movimiento físico del ratón y el desplazamiento del cursor en la pantalla. Una velocidad baja implicará que se necesite mucho movimiento del ratón para desplazar el cursor, mientras que una velocidad alta hará que el cursor se desplace mucho con poco movimiento del ratón.'

    text: '**Bloqueo del ratón**


      Para aquellos alumnos a los que les resulte más difícil mantener pulsado el botón del clic y a la vez desplazar el ratón, existe una opción para bloquear el clic hasta que se vuelva a pulsar. De esta manera, para dibujar, arrastrar elementos, seleccionar texto, etc., basta con hacer un clic un poco más largo para bloquearlo, desplazar el ratón hasta donde se quiera y volver a hacer clic para desbloquearlo.'
