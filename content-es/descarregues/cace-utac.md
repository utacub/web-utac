    [**Ejemplos de actividades con el vocabulario CACE-UTAC**](https://www.dropbox.com/scl/fi/dmh886fz78af4c3f4ct3m/Llista-d-activitats-vocabulari-CACE.docx?rlkey=hovyzb3zxukqcwbvvtrd1mvq7&st=muybfgs8&dl=0) - En este documento encontraréis una lista de actividades que se pueden llevar a cabo para enseñar a usar el léxico de este vocabulario.     Para aclarar cualquier duda que tengáis sobre cómo se instalan o utilizan los archivos que encontraréis en esta página podéis escribir un correo electrónico a [utac@ub.edu](mailto:utac@ub.edu) o bien a [utac.sirius.dretssocials@gencat.cat](mailto:utac.sirius.dretssocials@gencat.cat).
