    [**Sample activities with the CACE-UTAC vocabulary**](https://www.dropbox.com/scl/fi/dmh886fz78af4c3f4ct3m/Llista-d-activitats-vocabulari-CACE.docx?rlkey=hovyzb3zxukqcwbvvtrd1mvq7&st=muybfgs8&dl=0) (in Catalan) - This document contains a list of activities that can be carried out to teach the use of the words in this vocabulary. It should not be understood as a protocol or an intervention method; these are just some ideas that will need to be selected and adapted for each person.


    If you have any questions about how to install or use the files on this page, you can email [utac@ub.edu](mailto:utac@ub.edu) or [utac.sirius.dretssocials@gencat.cat](mailto:utac.sirius.dretssocials@gencat.cat).
