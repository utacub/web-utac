  - youtube: bSWnAmVLoVQ
    text: '**StickyKeys**


      This option lets us adapt the keyboard for people who use it with only one hand or who find it very difficult to press two keys at the same time. Once it is on, we can type characters that require key combinations (for example "?" or "@") by pressing the keys one after the other.'
  - youtube: 47izNxGgQxI
    text: '**Anti-tremor or "Typing protection"**


      By following the steps in the video, you can make a key not repeat until a set time has passed (which you can configure between 0.5 and 2.0 seconds) between one keystroke and the next.'
  - youtube: 88G85-LbLLY
    text: '**Anti-repeat**


      With this option on, pressing a key types it only once even if it is held down. This avoids many accidental repeated letters.'
  - youtube: hXBz-fceH4g
    text: '**"Prevent accidental keystrokes" (equivalent to SlowKeys in Windows XP)**


      "Slow keys" make a character appear only after the key has been held down for a set time (which can be configured between 0 and 20 seconds). This allows some people who find it hard to hit the key they want directly, but who can hold it down once they are on it, to use the keyboard.'
  - youtube: g9Vu6G4bwMs
    text: '**MouseKeys**


      When a person can use a keyboard but not a mouse, we can try this option to move the pointer with the numeric keypad. In Windows Vista you will see that it can be reached in two ways: "Make the mouse easier to use" and "Make the keyboard easier to use".'
